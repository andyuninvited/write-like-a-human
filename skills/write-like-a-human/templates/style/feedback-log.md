# Feedback Log

A dated record of every edit you made to an AI draft, newest first. The skill appends here when it runs the learning loop. A move that shows up twice gets promoted into `style-rules.md` or `rules.json`.

Entry format:

```
## YYYY-MM-DD - what was being written
- MOVE: what you changed, stated as a rule
- STATUS: new rule | existing rule violated | one-off | promoted
- EVIDENCE: the before and the after, one line each
```
