## Hard bans

| Banned | Use instead | Set |
|---|---|---|
| Em-dash | A period, a comma, or a spaced hyphen | starter |
| leverage, robust, seamless, streamline | Say what actually happens | starter |
| "not X, but Y" and "not X, it's Y" | State the positive claim and stop | starter |
| Throat-clearing openers ("In today's world") | Open on the first sentence that carries information | starter |
| Rule-of-three triplets by reflex | Keep the strongest item | starter |
| Restating closers ("In short") | Delete the sentence if the point already landed | starter |
