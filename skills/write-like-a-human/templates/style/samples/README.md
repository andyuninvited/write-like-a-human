# Samples

Put 3 to 10 pieces of writing you are proud of here, one per `.md` or `.txt` file. Use writing you did without AI help: emails you sent, posts, letters, or anything that sounds like you on a good day.

These are the ground truth. `write-like-a-human profile` reads them to build `profile.md`, and the skill reads them before drafting. Variety helps, so mix formats and audiences. This README is ignored by the profiler.
